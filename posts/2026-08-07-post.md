**What if your AI coding agent could work for 24+ hours straight — making over 1,000 tool calls — without a single human prompt?**

Meta's new Muse Code just did exactly that.

Released on August 5, Meta Superintelligence Labs dropped two things at once: Muse Spark 1.2, a 118B-parameter coding model (8B active per token, 1M context), and Muse Code (beta), a terminal coding agent that takes on entire software engineering tasks end-to-end.

Here's why developers should pay attention:

→ Muse Code plans changes, writes code, runs tests, and validates results across large codebases
→ It coordinates multiple persistent subagents working in parallel
→ Muse Spark 1.2 hits 82.9% on Terminal-Bench 2.1 — 2nd globally, beating GPT-5.6 Terra, Grok 4.5, and Gemini 3.6 Flash
→ In one live demo, the model autonomously optimized GPU kernels over 24+ hours

This is Meta's direct answer to Claude Code and OpenAI Codex. The terminal coding agent race just got three serious competitors.
