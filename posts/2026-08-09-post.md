**Your AI coding agent just got its biggest enterprise unlock yet.**

Anthropic opened a public beta this week for self-hosted environments in Claude Code — letting organizations run agent sessions on their own compute instead of Anthropic's cloud.

Here's what changes in practice: Claude Code sessions can now reach internal databases, build systems, and private registries that aren't exposed to the public internet. Repository checkouts, build artifacts, credentials, and every file an agent touches stay on machines your team controls.

For engineering and security leaders who've been holding back on Claude Code because "our data can't leave the network" — that objection just got answered.

The setup is available on Claude Team and Enterprise plans and is off by default. Platform teams provision the runners; individual developers get the same Claude Code experience they'd have on Anthropic's cloud, now fully connected to internal tooling.

This is how AI coding agents cross from productivity experiment to production infrastructure. The compliance gate just opened significantly wider.
