**AI voice deepfakes just got harder to hide.**

Yesterday, OpenAI quietly added SynthID watermarking to GPT-Live — the full-duplex voice model powering ChatGPT Voice. Every audio conversation generated through ChatGPT Voice or the OpenAI API now carries an invisible provenance signal embedded in the audio itself.

SynthID is Google DeepMind's audio watermarking technology. OpenAI's integration means AI-generated voice outputs can now be verified — even after editing, compression, or re-encoding.

What's available right now:
→ A public verification tool to detect OpenAI provenance signals in audio files
→ A new developer API so organizations can integrate audio provenance checks into their own workflows
→ SynthID complements (not replaces) C2PA metadata — double-layered authentication

For enterprises running voice AI, media organizations verifying sourced audio, or compliance teams worried about synthetic voice fraud, this changes the workflow. Authentication is now built in, not bolted on.

The broader signal: provenance is becoming infrastructure — not a product feature.
