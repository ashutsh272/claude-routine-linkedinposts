**An AI just found Chrome zero-day vulnerabilities that human researchers missed — and OpenAI is now offering it to security teams.**

OpenAI this week expanded its Daybreak cybersecurity program with GPT-5.6-Cyber, a model built on GPT-5.6 Sol with its safety guardrails for security-sensitive queries removed. The results are striking: on OpenAI's internal Advanced Cybersecurity Completion Rate benchmark, GPT-5.6-Cyber completes 95% of requests — compared to just 1.5% for the standard GPT-5.6 Sol.

To validate it, OpenAI deployed the model to hunt real vulnerabilities. It found two previously unknown flaws in V8, Chrome's JavaScript engine. Google has now patched them under CVE-2026-15903 — a high-severity (CVSS 8.8) memory corruption bug involving the V8 optimizing compiler.

For security and IT professionals, this changes the calculus on AI-assisted offensive and defensive research. The window between vulnerability discovery and exploitation is shrinking; AI is now on both sides.

Access is gated via Daybreak Red (identity verification, hardware security keys, legal attestations required). Pricing: $12.50/M input tokens, $75/M output.
